Livre Game Jam 2017

Uma game jam de 48 horas organizada por LivreCamp, Gamux e Fellowship of the game para promover o uso de software livre. Nossa equipe do USPGameDev foi à UNICAMP para participar. Nós fizemos o jogo “Network Battle: Chain Hostility” (em português, “Batalha na rede: Hostilidade em cadeia”), um jogo multijogador assimétrico sobre uma guerra cibernética entre um hacker e o governo.
